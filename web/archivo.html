01 · Mapa mental

Dos etapas, dos perfiles de reglas

Parcial · Guías 1-6

Control básico

  • Permitido: while por contador, funciones, punteros de salida y double.
  • Prohibido: for, break, continue, arreglos, strings, struct, bool, float y conteo de cifras con bucles.
  • Validación secuencial: primero leer y validar; luego procesar.
Laboratorios · Guías 8-9

Ciclos anidados

  • Se habilitan for, while anidado, centinelas, break y continue.
  • Se habilitan +=, *=, asignación en cascada y salida %02d.
  • Contar cifras ahora exige iteración: while (n != 0) { digitos++; n /= 10; }.
  • Intermedio/avanzado: 4-5 módulos, ciclos en main y subprogramas, dos salidas por referencia no lectoras.
Nota 0 en ambas etapas: arreglos, cadenas, struct, memoria dinámica, variables globales, bool, float y switch. En Guías 8-9, no olvides la cuota arquitectónica.

Puente con las guías previas

Fundamentos para resolver problemas

Datos y expresiones

Usa int para conteos y cifras; double para magnitudes fraccionarias. Revisa unidades, límites, división entera y precedencia antes de escribir la fórmula.

Secuencia y selección

Descompón el proceso en pasos y expresa cada decisión con if / else. Para comparar varias condiciones, conecta comparaciones completas con && o ||.

Iteración y centinelas

Inicializa antes del ciclo, define condición de salida y actualiza en cada vuelta. Combina contadores con centinelas y evita ciclos sin progreso.

Módulos y validación

Diseña de arriba hacia abajo: main coordina, módulos calculan y muestran. Valida scanf, dominio y rangos antes de usar los datos; documenta parámetros por valor y referencia.

Herramientas numéricas recurrentes: extrae cifras con % 10 y / 10; recorre de izquierda a derecha con potencias de diez; usa MCD por Euclides, primos hasta d*d ≤ n, divisores propios con límites explícitos, factorial iterativo y variables deslizantes para recurrencias. Ante double, compara con tolerancia.

02 · Laboratorio de memoria

Punteros y pila de llamadas

int suma, producto;
calcular_suma_y_producto_digitos(235,
                                  &suma, &producto);
void calcular_suma_y_producto_digitos(
    int num, int *p_suma, int *p_producto) {
    *p_suma = 0;
    *p_producto = 1;
    while (num != 0) {
        *p_suma += num % 10;
        *p_producto *= num % 10;
        num /= 10;
    }
}

Pulsa “Siguiente línea” para iniciar la traza.

Estado de memoria (Stack y marcos)

scanf("%d", p): p ya es una dirección cuando es parámetro puntero.

(*cont)++ o *cont += 1 incrementa el valor apuntado.

*cont++ incrementa el puntero por precedencia; no es lo mismo.

break sale solo del ciclo más interno que lo contiene.
